# Improv Telegram Bot

Telegram-бот для автоматизации воронки закрытого канала **Импрув**: обработка заявок на вступление, видеоурок, напоминания и консультация.

## Возможности

- Автоматическое сообщение при подаче заявки в закрытый канал
- **Принятие заявки в канал** при нажатии `/start` в боте
- Приветствие и видеоурок по команде `/start`
- **Опрос перед консультацией** (4 вопроса) с отправкой заявки админу
- FSM-состояния пользователя
- SQLite + SQLAlchemy для хранения данных
- Периодические напоминания по расписанию (видео: 3 сообщения, консультация: 4)
- Отложенная отправка сообщения о консультации
- Все тексты и настройки вынесены в конфигурационные файлы

## Быстрый старт

### 1. Установка зависимостей

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

### 2. Настройка окружения

```bash
copy .env.example .env
```

Заполните `.env`:

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен от @BotFather |
| `CHANNEL_ID` | ID канала (например `-1001234567890`) |
| `BOT_USERNAME` | Username бота без `@` |
| `ADMIN_ID` | Telegram ID админа (получает заявки на консультацию) |
| `YOUTUBE_VIDEO_URL` | Ссылка на видеоурок |
| `CONSULTATION_URL` | Ссылка на запись на консультацию (отправляется после опроса) |

### 3. Настройка бота в Telegram

1. Добавьте бота **администратором** в закрытый канал
2. Включите право **«Добавление участников»** (для обработки заявок)
3. Убедитесь, что канал работает через **заявки на вступление**

### 4. Запуск

```bash
python -m bot
```

## Настройка текстов

Все сообщения редактируются в `config/messages.yaml`:

- `join_request` — сообщение после заявки в канал
- `start` — приветствие по `/start`
- `consultation` — сообщение о консультации (+ `delay_minutes`, `link_text`)
- `survey` — вопросы опроса и шаблон сообщения админу
- `reminders.video` — 3 напоминания: сразу, +2ч, +1 день (`delays_minutes: [0, 120, 1440]`)
- `reminders.consultation` — 3 напоминания после основного: +2ч, +1 день, +2 дня

### Картинки

Положите файлы в `assets/` и укажите пути в `config/messages.yaml`:

| Сообщение | Ключ в yaml |
|---|---|
| Заявка в канал | `join_request.image` |
| Приветствие `/start` | `start.image` |
| Ссылка на видеоурок | `video_link.image` |
| Консультация | `consultation.image` |
| Ссылка после опроса | `consultation.link_image` |
| Напоминания о видео | `reminders.video.images` (по одной на каждое сообщение) |
| Напоминания о консультации | `reminders.consultation.images` (по одной на каждое сообщение) |

Вопросы опроса (`survey`) — **без картинок**.

Если файл не найден, бот отправит текст без фото и запишет предупреждение в лог.

## Отслеживание клика по видео

Telegram **не уведомляет бота** о нажатии на URL-кнопки. По умолчанию используется режим `callback`:

```yaml
buttons:
  video_mode: callback   # рекомендуется — отслеживание клика
  # video_mode: url    # прямая ссылка, без отслеживания
```

В режиме `callback` пользователь нажимает кнопку → бот фиксирует клик → отправляет ссылку на YouTube.

## Воронка пользователя

```mermaid
flowchart TD
    A[Заявка в канал] --> B[Сообщение со ссылкой на бота]
    B --> C[/start]
    C --> D[Бот принимает заявку в канал]
    D --> E[Приветствие + кнопка видеоурока]
    E --> F{Нажал кнопку?}
    F -->|Нет| G[3 напоминания: сразу / +2ч / +1д]
    G --> F
    F -->|Да| H[Через N минут — консультация]
    H --> I[4 сообщения: сразу / +2ч / +1д / +2д]
    I --> J[Нажал ЗАПИСАТЬСЯ]
    J --> K[Опрос: 4 вопроса]
    K --> L[Сохранение в БД + уведомление админу]
    L --> M[Ссылка на консультацию]
```
